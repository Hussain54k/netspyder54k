# NetSpyder54k: Targeted Social Media OSINT Scanner

**NetSpyder54k** is a specialized Open Source Intelligence (OSINT) reconnaissance tool written in **Python**. It automates username footprinting across the most popular social media networks (TikTok, Instagram, Snapchat, Telegram, Line) using active HTTP scanning.

## Disclaimer
*This tool is created strictly for educational purposes, authorized security assessments, and digital forensics research.*

## Features
* **Targeted Reconnaissance:** Focuses on the most popular social media networks to map a target's digital footprint.
* **Anti-Bot Bypassing:** Implements custom User-Agent headers to simulate real browser connection requests and avoid blocks.
* **Cross-Platform Support:** Runs natively on Windows and Linux terminal environments.

## Requirements
This tool requires the `requests` package.

### Installation
Open your terminal and install the dependencies:
```bash
pip install requests
```

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com
   cd netspyder54k
   ```
2. Run the script:
   ```bash
   python netspyder54k.py
   ```
